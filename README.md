These repositories are for personal utility projects based on my own ideas and needs.  
Each project starts from an idea I come up with, and is then further developed with AI assistance. I make the final decisions on specifications and check the actual behavior through normal use and additional checks when something seems worth testing.  
Most of the coding is produced by AI; I usually evaluate it by using the software rather than by detailed code review. Most of the documentation is also produced by AI and is reviewed by me before I use or publish it.
